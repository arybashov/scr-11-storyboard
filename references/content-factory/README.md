# Материалы «Контент-завода» для «Подземного перехода»

Взяты 10.11.2026 из `G:/_AVATAR_FACTORY`. Это копии проектных навыков и конспектов, а не тексты книг. Прочитаны перед монтажной редакцией 55,1 с.

Литература, на которую опирается конспект [film.md](factory/skills/film.md):

- Даниэль Арихон — «Грамматика киноязыка»: ось, расположение участников, направление взгляда.
- Джозеф Маскелли — «Пять “К” кинематографии»: крупности, композиция, непрерывность и монтаж.
- Уолтер Мёрч — «Мгновение ока»: приоритет эмоции, истории и ритма при выборе склейки.

Основной навык — [kinoplan](kinoplan/SKILL.md). Дополнительные конспекты: [камера](factory/skills/camera.md), [базовые схемы сцен](factory/skills/scenes.md). Пути `factory/...` в оригинальном kinoplan разрешаются относительно этой папки. Это справочные копии; весь пакет генераторов, упомянутый в навыке, здесь не устанавливался.

Сторонний навык [video](video/SKILL.md) и его материалы: [драматургия](video/references/dramaturgy.md), [универсальные правила](video/references/universal-rules.md), [режиссёр / сценарист / монтажёр](video/references/role-modes.md), [опорные кадры аниматика](video/references/animatic-keyframes.md).

**Атрибуция:** Serge Shima, [smixs/visual-skills](https://github.com/smixs/visual-skills), лицензия [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Копии `video/` перенесены без изменений из локального пакета «Контент-завода»; не утверждается, что это последняя версия upstream. Монтажные выводы для нашего фильма — отдельная адаптация.

В драме не применяем буквально заводские ограничения вертикальной комедии: 6–8 планов, спокойное лицо, запрет паники, одна декорация. Они противоречат задачам этой сцены. Сохраняем гнев, клаустрофобию, крик, сложную траекторию телефона. Не превращаем действующие референсные картинки в новые стартовые кадры генерации автоматически.

Применение: [монтажная записка](../../edits/20261110-rhythm.md).
